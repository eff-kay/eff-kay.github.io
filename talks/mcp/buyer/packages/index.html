Each host has a different intake

ChatGPT uses a plugin ZIP plus portal configuration and review. Claude and Cursor use their own repository layouts. Factory adds a Git marketplace wrapper. Muse has a connector intake and workflow review; Hermes uses a pinned catalog pull request. A working MCP endpoint alone does not complete any of these reviews.
